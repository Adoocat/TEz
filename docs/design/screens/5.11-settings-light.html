Sistem Entegrasyonu ve CLI Köprüsü

OS Level Interop

terminal

Terminal CLI Komutu (tez)

POSIX Uyumlu Shell Kütüphanesi
PATH'e Kuruldu (v1.4.0)

Terminalde tez search, tez add, tez export komutlarını doğrudan çalıştırabilmenizi sağlar.

Konum: /usr/local/bin/tez
Hızlı Örnek Kullanım zsh / bash / fish 
# Mevcut klasörü SLR çalışma alanı olarak başlat:
$ tez .

# DOI üzerinden kütüphaneye ve matrise otomatik çek:
$ tez add 10.1145/3611643.3616265 --matrix-auto-extract

link

Özel URL Şeması (tez://)

Derin Bağlantı (Deep Linking) Sistemi
Kayıtlı ve Aktif

LaTeX, Obsidian, Notion veya harici web tarayıcısından tıklanan alıntı linkleri doğrudan TEz okuyucusunu ilgili sayfada ve vurgulanmış pasajda açar.

Protokol Bağlantı Örneği:
tez://paper/sahin2024_ast?page=4&highlight=cf82
