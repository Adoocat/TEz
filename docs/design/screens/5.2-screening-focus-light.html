Evaluating LLM-Generated Code Review Comments for Security Vulnerabilities in Critical Infrastructure

article Özet (Abstract)
Vurgu anahtarı: Dahil Etme Terimi (I1, I2) Hariç Tutma Sinyali

Automated code review using large language models presents promising avenues to reduce software maintenance overhead and detect human oversights prior to integration. In this paper, we conduct an extensive empirical study across 12 open-source repositories governing critical industrial cyber-physical infrastructures. We evaluate whether state-of-the-art transformer architectures provide context-aware feedback on pull requests containing Common Weakness Enumerations (CWEs). Our findings indicate that while GPT-4 achieves 74% precision on syntactic defects, domain-specific security vulnerabilities are frequently missed unless augmented with semantic static analysis. We benchmark false-positive rejection rates and provide actionable guidelines for practitioners integrating neural review agents into high-reliability pipelines.
